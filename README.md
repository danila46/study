# БРС Dashboard

Простой фронтенд-дашборд для отслеживания:

- расписания на сегодня;
- текущих баллов по дисциплинам;
- прогнозируемых баллов на сегодня (если пойти на отмеченные занятия);
- порогов 40 / 60 / 80;
- ручного ввода баллов ТК.

## Запуск

```bash
cd /workspace/study
python3 -m http.server 4173 --bind 0.0.0.0
```

После запуска **ничего дополнительно вводить не нужно**: в терминале должно остаться сообщение вида:

```text
Serving HTTP on 0.0.0.0 port 4173
```

Это означает, что сервер работает. Откройте сайт по адресу:

- `http://localhost:4173` (если запускаете локально на своём ПК)
- `http://127.0.0.1:4173`

## Если вместо этого открывается интерактивный Python

Значит команда введена не полностью. Нужна именно команда с `-m http.server`:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

(с точкой в `http.server`, а не `http server`)
