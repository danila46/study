# БРС Dashboard

Простой фронтенд-дашборд для отслеживания:

- расписания на сегодня;
- текущих баллов по дисциплинам;
- прогнозируемых баллов на сегодня (если пойти на отмеченные занятия);
- порогов 40 / 60 / 80;
- ручного ввода баллов ТК.

## Если «не работает» через Python — используйте один из 3 способов

### Способ 1 (рекомендуется): `run-server.bat`

1. Откройте папку проекта.
2. Дважды кликните `run-server.bat`.
3. Откройте `http://localhost:4173`.

Что делает батник:

- переходит в папку проекта автоматически;
- пробует запустить сервер через `py`/`python`;
- если Python недоступен — автоматически запускает встроенный PowerShell-сервер (`run-server.ps1`).

### Способ 2: PowerShell-сервер без Python

Если Python на Windows ведёт себя странно (REPL, алиасы и т.п.), запустите напрямую:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run-server.ps1 -Port 4173 -Root .
```

### Способ 3: вручную через Python

```bat
py -m http.server 4173
```

или:

```bat
python -m http.server 4173
```

## Что делает команда `py -m http.server 4173`

- `py` — Python Launcher в Windows;
- `-m http.server` — запуск встроенного HTTP-сервера Python;
- `4173` — локальный порт.

Итог: локально раздаются файлы текущей папки (`index.html`, `styles.css`, `app.js`) по адресу `http://localhost:4173`.

## Если всё равно не открывается

1. Проверьте, что открываете именно `http://localhost:4173`.
2. Попробуйте другой порт:
   - в `run-server.bat` замените `set "PORT=4173"` на `set "PORT=8080"`;
   - откройте `http://localhost:8080`.
3. Закройте процессы, которые могли занять порт (старые `python.exe`).
4. Временно отключите VPN/прокси и проверьте снова.
