# БРС Dashboard

Простой фронтенд-дашборд для отслеживания:

- расписания на сегодня;
- текущих баллов по дисциплинам;
- прогнозируемых баллов на сегодня (если пойти на отмеченные занятия);
- порогов 40 / 60 / 80;
- ручного ввода баллов ТК.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.
