# БРС Dashboard

Простой фронтенд-дашборд для отслеживания:

- расписания на сегодня;
- текущих баллов по дисциплинам;
- прогнозируемых баллов на сегодня (если пойти на отмеченные занятия);
- порогов 40 / 60 / 80;
- ручного ввода баллов ТК.

## Быстрый запуск на Windows (через bat)

В проект добавлен файл `run-server.bat`.

1. Откройте папку проекта.
2. Дважды кликните `run-server.bat`.
3. В браузере откройте `http://localhost:4173`.

Остановка сервера: `Ctrl+C` в окне батника.

## Запуск на Windows вручную (cmd / PowerShell)

В папке проекта выполните **ровно одну** из команд:

```bat
py -m http.server 4173
```

или (если `py` не найден):

```bat
python -m http.server 4173
```

## Что делает команда `py -m http.server 4173`

- `py` — Python Launcher в Windows (запускает установленный Python);
- `-m http.server` — запускает встроенный модуль веб-сервера Python;
- `4173` — порт, на котором будет доступен сайт.

Итог: команда поднимает локальный HTTP-сервер и раздаёт файлы текущей папки (в нашем случае — `index.html`, `styles.css`, `app.js`).

После запуска команда должна "зависнуть" в этом окне и показать строку вида:

```text
Serving HTTP on 0.0.0.0 port 4173
```

Это нормальное поведение: сервер запущен.

## Запуск на Linux / macOS

```bash
cd /workspace/study
python3 -m http.server 4173 --bind 0.0.0.0
```

## Если в консоли появляется просто `Python` и ничего не происходит

Обычно это значит, что:

1. была вставлена лишняя строка (например `\nPython`) вместе с командой;
2. запустился интерактивный REPL вместо `http.server`;
3. команда введена с опечаткой (`http server` вместо `http.server`).

Что сделать:

1. Нажмите `Ctrl + C` (или `Ctrl + Z`, затем Enter), чтобы выйти из текущего режима.
2. Введите заново **только одну строку**:

```bat
py -m http.server 4173
```

3. Откройте `http://localhost:4173`.
